What is Hourglass?

Hourglass is a lightweight web UI for managing cron jobs on a Linux or macOS machine. You can view, add, edit, enable/disable, run, and delete scheduled jobs without touching the command line.

Managing jobs

  • Add a job — click Add New Job, enter a schedule (0 9 * * *), the command to run, and an optional comment (shown as the job name).
  • Edit — click the pencil icon on a job row to change its schedule, command, or comment.
  • Enable / Disable — click the pause/play icon to comment or uncomment a job without deleting it.
  • Run now — click the play icon to execute the job immediately (results are recorded in the logs).
  • Delete — click the trash icon and confirm. This cannot be undone.

The ? button next to the Schedule field shows a full cron syntax reference with a live preview.

Last run & status

Each job shows when it last ran and whether it succeeded (✓ / ✗). Hourglass records this by wrapping active jobs when it writes them to the crontab. Jobs installed outside Hourglass are automatically wrapped the first time they're viewed. The View Logs page shows the full execution history.

Connections

Hourglass manages one crontab at a time — either the machine it runs on (Local) or a remote machine you reach over SSH. Use Add Connection to save a remote host (hostname, SSH port, username, and private key path), then click Connect on a saved connection to switch to it. The UI shows which host you're currently connected to in the header.

Only one connection is active at a time, and the job list always shows the active connection's crontab — never a merged view.

Reaching a remote instance over SSH (tunneling)

Hourglass can be installed on another machine (for example a server that manages that machine's own crontab) and accessed from your laptop without exposing it to the network. The Hourglass service itself stays bound to 127.0.0.1 — it never listens on a public address like 0.0.0.0 — and your browser's connection to the UI travels through an encrypted SSH tunnel.

  1. On the remote machine, run Hourglass bound to localhost only: 
    HOURGLASS_BIND=127.0.0.1:8080 ./hourglass
    (or set HOURGLASS_BIND=127.0.0.1:8080 in its systemd/launchd unit). Loopback binds need no credentials.
  2. From your laptop, open an SSH tunnel to that machine: 
    ssh -L 8080:localhost:8080 user@remote-server
  3. Open http://localhost:8080 in your browser — you're now viewing the remote instance through the tunnel.

The tunnel keeps the connection private: the service is never reachable by other machines on the network, and all UI traffic is encrypted by SSH. If the remote instance has authentication enabled, you'll sign in normally over the tunnel.

Authentication

When Hourglass is bound to a non-loopback address (LAN-accessible), it generates credentials on first run and prints them to the log (Login: admin / <password>), saved in ~/.hourglass/auth.env. You can also set HOURGLASS_AUTH_USER and HOURGLASS_AUTH_PASS explicitly. Loopback binds (127.0.0.1) stay password-free.
